# 🐍 Python Assignment 1: Data Structures – Strings & Tuples

This repository contains solutions for basic Python operations involving **Strings** and **Tuples**.  
It demonstrates fundamental concepts like concatenation, slicing, indexing, and tuple manipulation.

---

## 📘 Topics Covered

### 1️⃣ Strings
- **Concatenation:** Combining multiple strings using the `+` operator.  
- **Slicing & Indexing:** Accessing specific parts of a string using slice notation.  
- **String Methods:** Applying built-in methods like `.upper()`, `.lower()`, `.capitalize()`, `.count()`, and `.replace()`.

### 2️⃣ Tuples
- **Creation:** Defining tuples with parentheses `()`.  
- **Concatenation:** Merging two tuples using the `+` operator.  
- **Repetition:** Repeating tuple elements using the `*` operator.  
- **Accessing Elements:** Using indexing and slicing to retrieve specific values.

---

## 🧩 Example Outputs

```python
# String Concatenation
string1 = "Hello "
string2 = "Deenu"
string3 = ", welcome to Python programming"
print(string1 + string2 + string3)
# Output: Hello Deenu, welcome to Python programming
# Tuple Operations
t1 = (10, 20, 30)
t2 = (40, 50, 60)
t_combine = t1 + t2
print(t_combine)
# Output: (10, 20, 30, 40, 50, 60)
